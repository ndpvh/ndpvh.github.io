I am a researcher working at the company <a href="https://m-path.io">m-Path Software</a>, focusing on the functionality of the company's apps before they reach academic researchers interested in using them. Previously, I was an academic researcher with a main interest in mathematical psychology and psychometrics. 

As a mathematical psychologist, I investigated the applicability of (non)linear models for understanding psychological phenomena, as exemplified by my research on the Affective Ising Model, the Minds for Mobile Agents pedestrian model, and the Attitudinal Blume-Capel model. As a psychometrician, I investigated the reliability and validity of repeated measurements, such as subjective measurements obtained through self-report questionnaires and more "objective" measurements obtained through local positioning systems. Additionally, I am interested in the connection between the qualitative phenomena that we are interested in and the quantitative ratings that we typically obtain from our studies (e.g., rating scales in emotion research).

Together with Dr. Kenny Yu and Dr. Maria Robinson, I co-founded the<a href="https://tmmpsych.vercel.app"> _Theory, Model, Measurement_</a> network, an international research network that aims to address the disconnect between psychological theory, computational models, and measurement.

## Interests:

- Dynamical systems
- Affect dynamics
- Pedestrian modeling
- Psychometrics

## Software:

--|--
<a href="https://gitlab.kuleuven.be/ppw-okpiv/researchers/u0123135/probabilistic-reward-task">probabilistic-reward-task</a> | A JavaScript package allowing for flexible definition of an experimental paradigm that allows participants to win and lose money in some consecutive trials. Relies heavily on the <a href="https://lab.js.org/">lab.js</a> module.
<a href="https://gitlab.kuleuven.be/ppw-okpiv/researchers/u0123135/InputModels">InputModels</a> | A Julia package that serves as an extension of the <a href="https://gitlab.kuleuven.be/ppw-okpiv/research/GradientDiffusion.jl">GradientDiffusion.jl</a> package. Allows users to estimate the models defined in <a href="https://gitlab.kuleuven.be/ppw-okpiv/research/GradientDiffusion.jl">GradientDiffusion.jl</a> while accounting for a set of external variables that serve as input to the models. 
<a href="https>//www.github.com/ndpvh/predped">predped</a> | An R package around the Minds for Mobile Agents (M4MA) pedestrian model. Allows users to simulate M4MA in a user-specified environment with user-specified characteristics of the agents. Also has some functionality allowing users to estimate the M4MA on movement data.
<a href="https://www.github.com/ndpvh/denoiser">denoiser</a> | An R package that allows for adding noise and filtering noise from location data. Was specifically created to allow for more realistic simulation and recovery studies performed with <a href="https>//www.github.com/ndpvh/predped">predped</a>.
<a href="https://github.com/Sigert-Ariens/impulseR">impulseR</a> | An R package that allows for the creation and interpretation of system responses when one or multiple impulses are given to the system.
